# Brandon — собрать и показать на Mac

Это архив исходников, а не готовая macOS-программа. Сборка выполняется **на Mac**.
В Windows готовый `.app` в этом пакете не собирался; запуск на macOS ещё требует
проверки. Дата подготовки: 18 октября 2026 года.

## 1. Что нужно один раз установить

- Mac с macOS 12 или новее. Поддерживаются Apple Silicon и Intel.
- Apple Command Line Tools. Полный Xcode для настольного приложения не обязателен:

  ```bash
  xcode-select --install
  ```

  Дождитесь завершения установки в системном окне.

- Node.js **24 LTS** с npm: официальный установщик на [nodejs.org](https://nodejs.org/en/download).
- Rust через rustup: [официальная установка](https://rustup.rs/).
  Если Rust уже установлен через rustup, повторно ставить его не нужно.

После установки закройте и снова откройте Terminal. Команды `node --version`,
`npm --version` и `rustup --version` должны работать.

Нужен интернет для первой загрузки библиотек. Docker, PostgreSQL, сервер Brandon,
аккаунт приложения и платная учётная запись Apple Developer для этой локальной
демосборки **не нужны**. Отдельно устанавливать pnpm не требуется.

## 2. Распаковать исходники и собрать

Распакуйте ZIP в обычную папку, например `Downloads/Brandon-mac-source`.
Откройте Terminal и перейдите в эту папку — можно набрать `cd `, перетащить папку
из Finder в Terminal и нажать Enter.

В корне должны лежать `Cargo.toml`, `package.json`, каталоги `apps` и `scripts`.
Затем выполните:

```bash
bash scripts/build-macos.sh
```

Скрипт проверит инструменты, загрузит закреплённый Rust 1.98.0 и pnpm 11.19.0,
установит зависимости по lock-файлам, проверит TypeScript и линтер, запустит тесты
Markdown/vault и соберёт приложение для архитектуры **этого Mac**.
Дождитесь строки `Shareable ZIP:`. Первая компиляция заметно дольше последующих;
понадобится свободное место под Rust и зависимости.

Если нужен один файл одновременно для Intel и Apple Silicon:

```bash
bash scripts/build-macos.sh --universal
```

Универсальная сборка компилирует две архитектуры и занимает больше времени/места.
Запускайте только один вариант сборки одновременно.

## 3. Где результат

Готовое приложение:

```text
target/<архитектура>/release/bundle/macos/Brandon.app
```

Архитектура: `aarch64-apple-darwin` для Apple Silicon, `x86_64-apple-darwin` для
Intel, `universal-apple-darwin` для обоих. В конце скрипт напечатает точную команду
`open "…/Brandon.app"`.

В папке **`dist-macos`** появится ZIP с готовым приложением. Его можно передать
другу; Rust и Node.js на компьютере, где только запускают готовый `.app`, не нужны.
ZIP создаётся штатным `ditto`, чтобы сохранить структуру приложения и подпись.

Это **ad-hoc** подпись для тестирования, не Developer ID и не нотариализация Apple.
При передаче на другой Mac macOS может показать предупреждение о непроверенном
разработчике. Для беспрепятственного публичного распространения нужна отдельная
подпись и нотариализация; скрипт не меняет настройки безопасности macOS.
Не публикуйте эту демосборку как проверенный подписанный релиз.

## 4. Что показать

1. Откройте Brandon и выберите пустую тестовую папку как vault. Для демонстрации
   лучше не брать единственную копию важных заметок.
2. Создайте заметку: Markdown, визуальное редактирование, таблица, блок кода с языком.
3. Создайте холст: карточки, перемещение, выделение нескольких объектов, связи.
4. Откройте задачи и календарь: создайте задачу и перенесите её на день.
5. На обычном холсте проверьте приближение, отдаление и дальний обзор большой сцены.

Основные команды приложения принимают **Cmd** так же, как Ctrl в Windows:
Cmd+N — заметка, Cmd+S — сохранить, Cmd+P — команды, Cmd+O — перейти к заметке.
Подписи некоторых горячих клавиш пока остаются Windows-ориентированными.

Rust/wgpu-рендер включается автоматически на **Windows/D3D12**; отдельной
лаборатории больше нет. На Mac используется обычный DOM/2D-рендер. Доска,
дальний обзор, редактор и планировщик остаются доступны
в исходниках; их реальную работу в WKWebView нужно проверить на этом Mac.

## Если сборка упала

- `xcrun` / SDK / linker: убедитесь, что Command Line Tools полностью установились.
- Нет `rustup` после установки: откройте новое окно Terminal.
- Ошибка загрузки Rust/npm/crates: проверьте доступ к официальным реестрам. Не
  удаляйте lock-файлы и не заменяйте версии на произвольные более новые.
- `--universal` слишком тяжёлый: соберите обычной командой без этого параметра.
- Пришлите последние 40–80 строк ошибки. Логи и пути могут содержать имя пользователя;
  не прикладывайте пароли, токены или содержимое личного vault.

## Что внутри исходного архива

Исходники приложений и Rust-crates, конфигурации, иконки, lock-файлы, скрипт сборки,
эта инструкция и тесты desktop. Нет `.git`, `node_modules`, `target`, готовых
Windows-бинарников, `.env`, локальных SQLite-файлов, demo-vault или личных заметок.
Для сборки desktop используется только `knowledge-desktop` и его зависимости;
серверные crates не требуют запуска сервера при этой сборке.
